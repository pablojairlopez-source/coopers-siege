# Glosario maestro es-419 / en-US

Los IDs internos no se traducen. Cooper, Pipa, Bongo y Roco, la marca Cooper's Siege y Cooper's Trophy se conservan. Los nombres escritos por jugadores, sus proyectos y códigos LAN se muestran literalmente.

Huesitos → **Supply Bones**; individual: **supply bone**. Galletas → **cookies**. Los nombres artísticos de mapas se adaptan sin cambiar medidas ni identificadores (Kilómetro Cero → Mile Zero).
